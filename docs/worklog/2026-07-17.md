# 2026-07-17 Worklog

## Interactive real/sim point-cloud overlay

- Added `scripts/export_real_sim_episode_overlay_rerun.py` to visualize a full real episode and a
  full sim episode together in one Rerun recording.
- Real and sim clouds, TCP positions/trails, and goals use separate entity paths and colors.
- Unequal episode lengths are synchronized by normalized progress while preserving both complete
  episodes. The exporter reads the mixed Zarr directly and does not assume simulator actions,
  validity masks, or robot segmentation masks.
- Added pure tests for episode boundaries and normalized-progress frame mapping.
- The remote server's default Python resolves `rerun-sdk==0.15.1`, while the local viewer is
  `rerun-cli==0.21.0`. Generated the transferable comparison artifact from an isolated
  `rerun-sdk==0.21.0` environment and record the writer SDK version in the summary JSON.
