## Define the ITPS-versus-reranking experiment protocol

- Added `docs/explainations/itps_reranking_experiment_plan.md`.
- Fixed stable combined task-and-constraint success as the primary paper outcome,
  retained ordinary combined success for interim pilots, and distinguished transient
  goal reach from stable goal holding.
- Defined task, constraint, motion, compute, and method-specific diagnostic metrics
  using executed ManiSkill trajectories as the common measurement source.
- Specified paired episodes, confidence intervals, paired method comparisons, and the
  separation between full-distribution and nominal-base-success-subset results.
- Proposed the initial experiment ladder: metric validation, nominal checkpoint gate,
  primary comparison, constraint difficulty, compute matching, method ablations,
  geometry targets, robustness, and world-model prediction quality.
- Audited the definitions against the current constrained-reach evaluator and listed
  the paper-scale metrics that are not yet logged.
- Added a required realistic-obstacle experiment before the primary comparison.
  Simulator actors must contribute naturally camera-visible points to the policy
  observation, while their known pose and collision primitives provide the identical
  constraint geometry used by reranking and ITPS. Point-cloud boundary inference is
  explicitly deferred to a later perception ablation.
- Added obstacle families, point-retention checks through cropping/goal-token
  insertion, world-model static-scene checks, geometry/render synchronization checks,
  and obstacle-specific logging fields.
- Made qualitative outputs a required experiment deliverable. Every reported run must
  produce paired simulator MP4 and Rerun `.rrd` artifacts for a deterministic,
  method-matched episode subset, plus an artifact manifest linking videos, point-cloud
  timelines, metrics, constraints, obstacle configs, checkpoint, and git commit.
- Defined the required Rerun contents: policy-visible point clouds with semantic
  categories, executed and candidate trajectories, obstacle collision geometry,
  clearance state, ITPS/reranking diagnostics, and imagined-versus-executed world-model
  overlays where applicable.
