## Make 3 cm obstacle clearance the default

- Added one shared `DEFAULT_AVOID_MARGIN_M = 0.03` for avoidance constraints and JSON configs
  that omit a margin.
- Changed both constraint-generation CLIs to default `--avoid-margin` to 3 cm.
- The constrained evaluator now applies its requested margin to precomputed constraints as well,
  preventing historical serialized `margin: 0` values from silently disabling the current safety
  policy.
- Executed collision termination defaults to the same margin and compares the raw robot-to-obstacle
  distance against 3 cm. This avoids double-counting the margin because reporting clearances already
  subtract the constraint margin.
- Updated locked E3 protocol commands to pass the 3 cm planning and terminal margins explicitly.
  Its initial-clearance gate is zero in margin-adjusted coordinates, equivalent to 3 cm raw
  clearance.
