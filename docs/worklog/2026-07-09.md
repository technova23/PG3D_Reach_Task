# 2026-07-09 Worklog

## xArm M2 base-frame branch

- Created the `m2-base-frame-sim` branch to keep the existing M1 setup available on `main`.
- Switched xArm sim defaults to M2/base-frame coordinates: robot base at world origin, xArm
  reach/crop bounds equal their base-relative boxes, and xArm workspace/balanced env defaults use
  xArm-native base-frame goal distributions instead of Panda task specs.
- Added `scripts/convert_xarm_m1_to_m2.py`, a one-way converter for old M1 xArm sim Zarrs and
  precomputed constraint JSONs. It shifts Cartesian XYZ fields by `[0.615, 0, 0]` and leaves joint
  state/action, masks, sizes, axes, and orientations unchanged.
- Added simulator-free tests for M2 constants/defaults and converter behavior.

Validation:
